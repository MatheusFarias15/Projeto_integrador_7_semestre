[Tarefa 5] FEATURE ENGINEERING E TREINAMENTO DE IA
Status: CONCLUIDO
Arquivo: machine_learning/glucose_trainer.py (350 linhas)

Classe GlucoseTrainer com metodos:
- load_data() - preparacao e normalizacao de features
- train_xgboost() - XGBoost Regressor (100 estimadores)
- train_random_forest() - Random Forest (100 trees)
- train_gradient_boosting() - Gradient Boosting (100 estimadores)
- evaluate_model() - calcula R2, RMSE, MAE, MAPE
- compute_feature_importance() - 5 metodos diferentes:
  1. Pearson correlation
  2. Spearman correlation
  3. Mutual Information
  4. Model Feature Importance
  5. SHAP values
- select_best_model() - seleciona modelo com melhor R2
- save_model() / save_scaler() - persistencia em .pkl
- generate_report() / save_report() - relatorios em JSON

CLI de Treinamento:
Arquivo: train_glucose_model_cli.py (150 linhas)
- Script standalone para treinamento
- Carrega dados de ml_training_data
- Filtra apenas registros com glicose_real validada
- Treina 3 modelos em sequencia
- Salva modelo, scaler, relatorio
- Output formatado em stdout

COMO USAR?
==========

PASSO 1: Instalar dependencias
  pip install -r requirements.txt

PASSO 2: Terminal 1 - Captura de Sensores
  python serial_reader.py
  > Abrindo porta serial: COM5 @ 115200
  > Leitura de sensor enviada: {...}

PASSO 3: Terminal 2 - Backend Flask
  python app.py
  > Running on http://127.0.0.1:5000

PASSO 4: Terminal 3 - Dashboard Streamlit
  streamlit run dashboard.py
  > http://localhost:8501
  > Ir para aba "Treinamento IA"

PASSO 5: Coletar dados (repetir 10+ vezes)
  a) Execute serial_reader.py
  b) Meça glicose com glucosimetro
  c) Dashboard: registre glicose real
  d) Preencer dados demograficos
  e) Clique "Salvar Glicose Real"

PASSO 6: Terminal 4 - Treinamento
  python train_glucose_model_cli.py
  > [1/5] Carregando dados...
  > [2/5] Inicializando trainer...
  > [3/5] Preparando dados...
  > [4/5] Treinando modelos...
  >   XGBOOST: R2=0.8234, RMSE=12.45
  >   RANDOM_FOREST: R2=0.7891, RMSE=14.12
  >   GRADIENT_BOOSTING: R2=0.8156, RMSE=13.01
  > [5/5] Salvando modelos...

PASSO 7: Visualizar Resultados
  > Dashboard: aba "Analise"
  > Ver graficos de desempenho
  > Ver feature importance (5 metodos)
